# exo-site-staging
Staging build of the website for project exo.

Static files derived from `site/` at [Exo commit da5cfe8059e60ebafd40843623bad3d442796c87](https://github.com/Moissanite-Labs/exo/commit/da5cfe8059e60ebafd40843623bad3d442796c87). The repository links reflect the public organization. This site is served by GitHub Pages.

Staging HTML pages include noindex directives. `robots.txt` permits crawlers to read them. These directives are not access controls. GitHub Pages does not support the Vercel `X-Robots-Tag` response header, so non-HTML assets do not receive it.
